## Ficha

| Campo | Valor |
|---|---|
| Cliente / marca | |
| Workflow | commercial / cinematic / product-showcase |
| Duração | 15s / 30s / 60s |
| Formatos de entrega | 16:9 4K · 16:9 1080p · 9:16 · 1:1 |
| Prazo | |
| Status | brief · roteiro · storyboard · edição · revisão · entregue |

## Pastas

- `brief/` — briefing do cliente, referências, objetivos, público
- `scripts/` — roteiro e texto de locução (versões numeradas)
- `storyboard/` — quadros, shot list, animatic
- `footage/` — material bruto deste projeto (fora do git)
- `public/` — arquivos estáticos usados pelo Remotion (`staticFile()`)
- `src/` — composições Remotion
- `audio/` — trilha, SFX e locução finais deste projeto (fora do git)
- `renders/` — renders de revisão (fora do git); entregas finais vão para `EXPORTS/`
